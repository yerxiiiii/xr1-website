## 一、用什么软件？

| 用途 | 推荐软件 | 说明 |
|------|----------|------|
| **修图 / 导出 JPG、PNG** | Photoshop、Affinity Photo、[Figma](https://figma.com)、[Photopea](https://www.photopea.com)（免费网页版） | 调色、裁切、导出 Web 用图 |
| **3D 渲染 / 场景图** | Blender、KeyShot、原有 AIGC 出图工具 | 导出横图或竖图，再按下方尺寸建议压缩 |
| **看图、改尺寸（Mac）** | 预览（Preview）、系统「照片」 | 快速缩放；命令行可用 `sips -Z 1600 文件名.jpg` |
| **改网页里「引用哪张图」** | **Cursor** 或 **VS Code** | 只改文字路径，不必须在 PS 里做 |
| **看效果** | 浏览器 + 终端 `npm run dev` | 改完保存，浏览器刷新（有时需强刷 `Cmd+Shift+R`） |

不需要改代码的人也能：**先把图丢进文件夹**，再让设计/开发按本表改 `index.html` 一行。

## 五、怎么把灰色占位换成真图？

在 `index.html` 找到对应 `[图-xx]` 注释，把 **整个** `<div class="media-placeholder …">…</div>` 换成：

```html
<img
  src="/images/hero.jpg"
  alt="XR1 在后厨环境中工作"
  width="1200"
  height="900"
  loading="lazy"
  decoding="async"
/>
```

- 首屏第一张：`loading` 可改为 `fetchpriority="high"`，并去掉 `lazy`
- `src` 路径必须以 `/images/` 开头（对应 `public/images/` 文件夹）
- `alt` 填简短中文，方便无障碍与 SEO

**图-02 全屏背景示例**（保留底部文字渐变时，给 img 加 class，或继续用 CSS 背景—开发可协助）。

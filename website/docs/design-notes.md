## 版式原则

- 背景：近白 `#f7f7f7`，极少色块；深色仅用于主按钮
- 导航：**单行顶栏**，与页面区块一一对应（产品→方案→设计→技术→案例→产线→参数），滚动自动高亮；右侧「商务洽谈」
- ~~产品子导航~~ 已合并进顶栏，避免与「参数 / 产品 / 商务洽谈」重复
- 媒体：大圆角占位块（`border-radius: 2rem`），暂不铺实拍图
- 章节：全屏沉浸 → 横向轮播 → 双栏 Story → 参数列表 → 订阅 CTA → 多栏 Footer
